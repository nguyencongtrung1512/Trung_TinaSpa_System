# Skill: Song ngữ VI/EN & chống giật layout

Áp dụng khi thêm hoặc sửa bất kỳ trang/component công khai nào trong `Website_TinaSpa/app`.

## 1. Cấu trúc
| Thành phần | Vị trí |
| --- | --- |
| Cấu hình i18next, `setLanguage`, `currentLanguage`, `useContent` | `app/i18n/index.ts` |
| Bản dịch | `app/i18n/locales/vi.ts`, `app/i18n/locales/en.ts` |
| Nút chuyển ngôn ngữ | `app/components/ui/LanguageSwitcher.tsx` |
| Chữ cố định kích thước | `app/components/ui/StableText.tsx` |

- Tiếng Việt là mặc định. Lần render đầu luôn là `vi` (khớp HTML prerender), sau hydrate mới áp ngôn ngữ đã lưu ở localStorage (`tinaspa-lang`) hoặc ngôn ngữ trình duyệt.
- `en.ts` khai báo `const en: typeof vi`, nên thiếu hoặc thừa key sẽ báo lỗi TypeScript.
- Đổi ngôn ngữ trong code bằng `setLanguage('en')`, không gọi trực tiếp `i18n.changeLanguage`.

## 2. Quy tắc viết chữ
1. Không viết chữ cứng trong JSX. Thêm key vào **cả** `vi.ts` và `en.ts`.
2. Dữ liệu trong `app/data/*` chỉ giữ phần không phải chữ (id, ảnh, giá, icon). Chữ đặt trong locale theo id, ghép bằng hook dùng `useContent<T>(key)`.
3. `meta()` của route dùng `i18n.t(...)` (không dùng hook).
4. Lỗi validate lưu **key** (`'booking.errors.phone'`) thay vì chuỗi đã dịch, để tự đổi theo ngôn ngữ.
5. Giá luôn định dạng `vi-VN` với đơn vị `đ`.

## 3. Chống giật layout khi đổi ngôn ngữ
Bản dịch dài ngắn khác nhau sẽ làm nút co giãn và đẩy phần tử bên cạnh hoặc bên dưới. Dùng `StableText`: mọi bản dịch chồng trong cùng một ô grid, nên kích thước luôn bằng bản dài nhất. Các bản không dùng có `invisible` nên trình đọc màn hình chỉ đọc bản hiện tại.

```tsx
// Nút, link nav, tab, chip, nhãn cạnh control: giữ chiều rộng
<Link to='/booking' className='...'>
  <StableText i18nKey='nav.bookNow' />
</Link>

// Tiêu đề / đoạn văn phía trên nút hoặc nội dung quan trọng: giữ chiều cao
<h1 className='...'>
  <StableText i18nKey='hero.title' block />
</h1>

// Key động và căn lề
<StableText i18nKey={`products.categories.${id}`} align='start' />
```

| Trường hợp | Cách làm |
| --- | --- |
| Nút, link nav, tab, chip lọc, breadcrumb | `StableText` (inline) |
| Tiêu đề, mô tả ở hero / đầu trang / thẻ có nút bên dưới | `StableText block` |
| `<select>` hoặc input hiển thị chữ | chiều rộng cố định (`w-40`, `w-44`…) đủ cho bản dài nhất |
| Văn bản dài cuối section, nội dung tab chi tiết | `t()` thường, chấp nhận reflow |
| `alt`, `aria-label`, `placeholder`, meta | `t()` thường (không phải layout) |

Lưu ý:
- `StableText` render mọi ngôn ngữ, vì vậy chỉ dùng cho chữ ngắn hoặc khối quan trọng, không bọc cả bài viết dài.
- `align` mặc định: `center` cho inline, `start` cho `block`. Truyền `align` khớp với căn lề của khối chứa.
- Truyền `values` cho interpolation: `<StableText i18nKey='products.list.count' values={{ count }} />`.

## 4. Kiểm tra trước khi xong
1. `npx tsc --noEmit` và `npx eslint app` sạch.
2. Mở trang, bấm VI ↔ EN và xác nhận vị trí nút/link không đổi. Có thể đo nhanh trong console:
   ```js
   [...document.querySelectorAll('main a, main button')]
     .map((e) => { const r = e.getBoundingClientRect(); return `${r.left},${r.top + scrollY},${r.width}` })
   ```
   Kết quả phải giống nhau ở hai ngôn ngữ.
3. Kiểm tra cả desktop (1280px) và mobile (390px).
